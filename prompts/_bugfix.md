## Instructions for Claude Code
1. Reproduce it first. If it's in the simulation, write a failing test that shows it.
2. Find the root cause; don't just hide the symptom.
3. Fix it with the smallest sensible change, and confirm the test passes and nothing else broke.
4. Add it to "Known issues" (marked fixed) in PROGRESS.md with a one-line cause.
5. Tell the owner in plain words what was wrong and how to check the fix.
